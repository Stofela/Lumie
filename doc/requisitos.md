# Requisitos e escopo — Lumiê

## Objetivo

Desenvolver um ambiente web de apoio à experiência de estudo, com estratégias de foco e incentivo ao respeito ao ritmo individual.

## Público-alvo

Estudantes do ensino superior que desejam experimentar estratégias para lidar com dificuldades de foco, motivação e continuidade dos estudos.

## Requisitos funcionais

| ID | Requisito | Estado atual |
|---|---|---|
| RF01 | Exibir página inicial e navegação | Implementado |
| RF02 | Apresentar informações sobre o projeto | Implementado |
| RF03 | Exibir interface de login e cadastro | Implementado |
| RF04 | Alternar entre os formulários de login e cadastro | Implementado |
| RF05 | Criar conta usando Firebase Authentication | Em desenvolvimento: SDK importado, interface não conectada |
| RF06 | Autenticar usuário usando Firebase Authentication | Em desenvolvimento: SDK importado, interface não conectada |
| RF07 | Recuperar senha | Planejado |
| RF08 | Exibir e iniciar missões de estudo | Planejado; existe apenas função JS inicial sem tela correspondente |
| RF09 | Disponibilizar modo foco | Planejado |
| RF10 | Registrar progresso e reflexões | Planejado |

## Requisitos não funcionais

- RNF01 — A interface deve adaptar-se a telas menores.
- RNF02 — A navegação deve ser compreensível e consistente.
- RNF03 — Os elementos interativos devem apresentar foco visual ao navegar por teclado.
- RNF04 — Dados pessoais devem ser tratados com cuidado e protegidos por regras de acesso apropriadas.
- RNF05 — Credenciais privadas e segredos não devem ser versionados no Git.

## Fora do escopo desta versão

- Diagnóstico ou tratamento de condições de saúde.
- Substituição de acompanhamento psicológico ou profissional.
- Garantia de resultados acadêmicos ou clínicos.
